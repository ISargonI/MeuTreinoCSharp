## Como Rodar o Projeto no Antigravity

Você pode rodar de duas formas muito simples:

### Opção 1: Diretamente pelo Terminal Integrado do Antigravity (Recomendado para Interagir)
O Antigravity possui um terminal integrado (igual ao do VS Code).
1. No teclado, pressione o atalho **`Ctrl + '`** (ou `Ctrl + ~` / Menu Superior: **Terminal** -> **New Terminal**).
2. Cole e aperte Enter:
   ```powershell
   dotnet run --project src/PostoOasis.App/PostoOasis.App.csproj
   ```
3. A janela gráfica do **Auto Posto Oásis** abrirá na sua área de trabalho.

---

### Opção 2: O Assistente Abrir a Janela para Você
Se você pedir para o assistente abrir a janela, ele pode disparar o processo do Windows para que a aplicação desktop se abra na sua tela.
